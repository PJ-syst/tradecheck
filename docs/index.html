The captioned demo uses fixture prices, a strict parser, and simulated funds. It shows rejection, revision, approval, and audit history. No real trading is demonstrated.

Built and tested

  • Server-enforced budgets, reserves, and allowed markets.
  • Expiring previews and atomic, idempotent paper approvals.
  • Public Binance prices and exchange-filter estimates.
  • Optional structured model interpretation and reviewable rule proposals.
  • A read-only MCP adapter with a separate account display.

Integration status

Public Binance data and genuine Codex OAuth login have been verified. Authenticated discovery returned 50 tools; the required Spot balance and commission tools were absent from that inventory. The custom TradeCheck OAuth client was rejected and its login is disabled. Dashboard account activation and live model verification remain pending.

This is a local prototype, not an exchange execution service. Real orders, transfers, and withdrawals are not implemented.
